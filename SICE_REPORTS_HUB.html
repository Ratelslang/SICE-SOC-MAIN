🔒 End-of-Day Report

📋 Type: Daily Security Report
📅 Frequency: Daily (end of shift)
⏱️ Time to complete: ~3-5 minutes
💾 Export formats: PDF + WhatsApp

Document end-of-day security status. Check premises (gates, alarm, CCTV), note any incidents, and send summary to team via WhatsApp or PDF.

🛡️ Movement Log

📋 Type: Personnel Tracking
📅 When to use: Site visits, escorts, extractions
⏱️ Time to complete: ~2-3 minutes
🔄 Auto-calculate: Duration (arrival - departure)

Log all personnel movements. Automatically calculates duration, exports as PDF or WhatsApp format for instant team notification.

📊 Monthly Security Summary

📋 Type: Comprehensive Report
📅 Frequency: Monthly (end of month)
📄 Format: PDF (4-5 pages)
🔧 How to use: Edit template, run command

Professional monthly report with metrics, observations, and recommendations. Template-based (you fill in numbers each month). Run from terminal:

python3 generate_monthly_report_TEMPLATE.py 7 2026
